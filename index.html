Asset tools

Download a Roblox asset

Paste a catalog link or enter an asset ID. Roblox will return the original asset file when your API key is allowed to access it.

Supports Roblox catalog, create/store, and asset links.

File formats vary. Roblox 3D items may download as a Roblox model (.rbxm/.rbxmx) or mesh data (.mesh). They are not necessarily downloadable as OBJ, FBX, or GLB.

Downloads are requested from Roblox Asset Delivery.
