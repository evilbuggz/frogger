Download a Roblox asset

Paste a catalog link or enter an asset ID. Roblox will return the original asset file when your API key is allowed to access it.

Supports Roblox catalog, create/store, and asset links. Conversion runs in your browser.

Downloads: Choose the GLB model, a PNG texture, or a ZIP containing both. GLB stores the model, UV coordinates, materials, and available embedded textures in a Blender-importable file.

Downloads are requested from Roblox Asset Delivery.
